    How K-Map works

    1. Convert the Boolean function into minterms.
    2. Place 1s in the corresponding K-Map cells.
    3. Make groups containing 1, 2, 4, 8... adjacent cells. Groups can wrap around edges.
    4. Use the largest possible groups to eliminate variables.
    5. Write the remaining literals as the simplified Boolean expression.
